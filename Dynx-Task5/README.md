# Task 5 - Pass/Fail Classifier

## Objective
Build a machine learning classification model to predict whether a student will pass or fail based on study-related features.

## Activities Performed
- Loaded and analyzed the dataset
- Converted pass/fail labels into numeric format
- Trained a Logistic Regression model
- Predicted student outcomes
- Evaluated model accuracy
- Generated a confusion matrix

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Concepts Used
- Supervised Learning
- Classification
- Logistic Regression
- Confusion Matrix
- Accuracy Evaluation
