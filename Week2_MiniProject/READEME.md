# Week 2 Mini Project - Breast Cancer Classification

## Objective

Develop a supervised machine learning model to classify breast cancer tumors as Malignant or Benign using the Breast Cancer Wisconsin Dataset.

## Dataset

Breast Cancer Wisconsin Dataset

## Problem Statement

Early detection of breast cancer is critical for effective treatment. The goal of this project is to build a machine learning model that can predict whether a tumor is malignant or benign based on diagnostic measurements.

## Methodology

* Data Loading and Exploration
* Data Preprocessing
* Feature Selection
* Train-Test Split
* Model Training
* Model Evaluation
* Performance Analysis

## Machine Learning Model

* Logistic Regression

## Evaluation Metrics

* Accuracy Score
* Confusion Matrix
* Classification Report

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab

## Outcome

The model successfully classified breast cancer cases and achieved high prediction accuracy, demonstrating the effectiveness of supervised machine learning in healthcare applications.
