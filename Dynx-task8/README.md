# Task 3 - Model Optimization and Comparison

## Objective
To compare the performance of two clustering algorithms, K-Means Clustering and Hierarchical Clustering, using the Mall Customer Segmentation dataset and identify the most effective model for customer segmentation.

## Dataset
Mall Customer Segmentation Dataset

## Features Used
- Annual Income (k$)
- Spending Score (1-100)

## Models Compared
1. K-Means Clustering
2. Hierarchical Clustering (Agglomerative Clustering)

## Methodology
- Loaded and analyzed the dataset
- Selected relevant customer features
- Applied K-Means Clustering
- Applied Hierarchical Clustering
- Evaluated both models using Silhouette Score
- Compared model performance using a comparison table
- Visualized customer segments

## Evaluation Metric
- Silhouette Score

## Results
The performance of both clustering algorithms was compared based on cluster quality and separation. The model with the higher Silhouette Score was identified as the better-performing clustering technique.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Learning Outcomes
- Understanding of Unsupervised Machine Learning
- Customer Segmentation using Clustering
- Model Performance Evaluation
- Comparison of Different Clustering Algorithms
- Data Visualization and Interpretation

## Conclusion
Both K-Means and Hierarchical Clustering successfully segmented customers into meaningful groups. Based on the Silhouette Score comparison, the better-performing model was selected as the recommended approach for customer segmentation on this dataset.
