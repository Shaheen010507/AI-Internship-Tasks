# Task 7 - Mall Customer Segmentation using K-Means Clustering

## Objective
Perform customer segmentation using K-Means Clustering and identify customer groups based on spending behavior.

## Activities Performed
- Loaded and analyzed mall customer dataset
- Selected important customer features
- Applied K-Means Clustering
- Determined optimal K value using Elbow Method
- Visualized customer clusters on a 2D graph
- Analyzed clustering insights

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Concepts Used
- Unsupervised Learning
- K-Means Clustering
- Elbow Method
- Cluster Visualization
